# Numerical experiments for *Bias versus Tail Concentration Tradeoffs for Stochastic Approximation Algorithms*

This directory contains the reproducibility notebook for the numerical experiments in the manuscript.

## Contents

- `stochastic_approximation_simulations.ipynb`: self-contained simulation code, explanations, and embedded results.
- `figures/`: PNG files generated by the notebook.
- `requirements.txt`: tested Python dependencies.


## Run locally

```bash
python -m pip install -r requirements.txt
jupyter lab stochastic_approximation_simulations.ipynb
```

Then run all cells from top to bottom. No external data or network access is required. Fixed random seeds are included in the notebook.
